# ログ・稼働情報の収集対象

このリポジトリのNixOS＋Incusホストが対象。期間・サービス名で絞らず、以下を収集する。

## ログ

- ホストの `/var/log` と `/run/log/journal`。ローテート済みのログも含む。
- ホストのjournal全体と、`/var/log/journal/remote` に集約されたjournal。
- 接続ユーザーがIncusで操作できる各コンテナの `/var/log`、`/run/log/journal`、journal全体。
- 全保持ブート分のカーネルログ。

ファイルログは上記ディレクトリ内が対象で、シンボリックリンクは辿らない。
範囲外・解決不能のリンクは `log-symlinks.tsv` に、取得失敗や時間・容量制限による欠落は収集記録に残す。

## ログ以外の情報

- 時刻、ホスト名、OS・カーネル、プロセス一覧と実行ファイルのリンク先、ソケット。
- ユーザー・グループ、ログインセッション、SSH実効設定、authorized_keysの鍵指紋。
- systemdサービス・unit・timer・override、journalの保持状況、NixOS世代。
- Incusのプロジェクト・インスタンス・設定・信頼一覧・ネットワーク・ACL・forward・ストレージ。
- IPアドレス、経路、nftables、マウント、ディスク空き容量。
- systemd・cron・SSH・シェル設定、一時領域、シークレット保存先などのファイルメタデータ。
- 収集日時、各コマンドの終了コード・標準エラー。

秘密鍵・SOPS平文・アプリDB・プロセス環境変数・メモリは直接の収集対象にしない。
ただし、ログや設定情報自体には個人情報・認証情報が含まれる場合がある。
